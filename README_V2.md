# MacroRelay Studio

기존 AutoHotkey 매크로 빌더의 데이터 형식을 유지하면서 UI와 실행 구조를 재구축한 MacroRelay 제품군입니다.

## 실행

`run_gui.bat`을 더블클릭합니다. 기존 가상환경이 있으면 패키지를 다시 설치하지 않고 바로 실행합니다.

## 화면 구성

- 대시보드: 매크로·단계·이미지 통계와 프로젝트 오류를 표시합니다.
- 노드 매크로 빌더: 저장된 노드 위치를 복원하고 성공·실패 포트를 연결해 흐름을 시각적으로 편집합니다.
- 이미지 편집: 범위 캡처, 자르기, 회전·반전, 색상 보정, 지우개, 색상 제거와 원본 백업을 지원합니다.
- 데이터 테이블: 입력 데이터를 표 형태로 편집하며 저장 전 자동 백업합니다.
- Quick Slots: 3×5 슬롯을 Studio에서만 설정하고 초경량 MacroRelay Runner로 실행합니다.
- Studio 단축키: 이전 버전의 기능별 단축키 설정을 복원해 화면 이동과 주요 빌더 기능을 사용자 키로 지정합니다.
- 내보내기: AHK 미리보기, EXE 컴파일, 테스트 실행을 제공합니다.
- 진단 및 설정: 누락된 테이블·잘못된 이미지 영역·실행 환경을 점검합니다.

## 안전 장치

- 매크로를 저장할 때 `.history`에 최근 20개 버전을 보관합니다.
- 삭제 기능은 기본적으로 `.archive` 또는 `assets/.trash`로 이동합니다.
- 테이블 사용 매크로를 내보낼 때 참조한 테이블만 AHK에 포함합니다.
- 연결이 없는 기존 다단계 매크로는 순서대로 계속 실행합니다.
- 0×0 이미지 검색 영역은 내보낼 때 제외합니다.

## MacroRelay Runner

- AutoHotkey만 상주하며 Python과 PySide6는 평상시 실행하지 않습니다.
- 타이머나 화면 폴링 없이 Windows 전역 단축키 이벤트만 기다립니다.
- Quick Slots 저장 시 필요한 슬롯 스크립트만 `runtime/slots/`에 갱신합니다.
- `Ctrl+Alt+Pause`로 Runner가 시작한 매크로를 긴급 중지할 수 있습니다.
- Windows 자동 시작 여부는 MacroRelay Studio의 Quick Slots 화면에서만 변경합니다.

## Flow Canvas

- 기존 `graph_positions`, `graph_start_step`, `graph_end_step` 데이터를 그대로 사용합니다.
- 액션 종류별 컬러 노드, 성공·실패 곡선 연결, 연결 딜레이와 미니맵을 제공합니다.
- 휠로 확대/축소하고 가운데 마우스 버튼으로 캔버스를 이동합니다.
- 포트를 다른 노드로 드래그해 연결하며, 연결선을 우클릭해 끊거나 딜레이를 설정합니다.
- 노드 플로우가 기본 화면이고 기존 단계 목록·고급 JSON 편집도 보조 탭으로 유지됩니다.

## 데이터 위치

기존 폴더 구조를 그대로 사용합니다.

- `macros/`: 매크로 JSON
- `assets/`: 이미지 및 `index.json`
- `data_tables.json`: 데이터 테이블
- `hotkeys.json`: 빠른 실행 슬롯
- `runtime/`: MacroRelay Runner와 생성된 슬롯 스크립트
- `exports/`: AHK·EXE 결과물

구형 GUI와 코드 백업은 `_archive/rebuild-20260820/`에 보관됩니다.
